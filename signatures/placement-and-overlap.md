# Signature Placement and Overlap

Well-being is a circle around the lot. Zoning cell ≈ 8 m. Bonuses in an overlap ADD on the same homes; new homes usually beat stacking until that overlay is already green.

## Overlap if you drop two of the same radius
| Spacing | Overlap of one circle | Meaning |
|---|---|---|
| Same lot (0) | 100% | Dead. Do not. |
| 0.5 × diameter (d = r) | 39% | Stacking. Only if that patch is still deep red. |
| 0.75 × diameter (d = 1.5 r) | 14% | Use this. ~86% new homes. |
| Touching (d = 2 r) | 0% | Clean, small gaps in the corners. Fill gaps with parks. |
| Farther | 0% + dead land between | Fine if those tiles are industry. |

## Council spacing rule
Open Well-being overlay. If patch is red/yellow: place signature so circle eats that patch; next signature of similar r: center 1.5 r away. If patch is already green: skip; spend the building on the next red patch. If a large-r signature is coming this milestone: park the small one on the edge, not under the future tower.
