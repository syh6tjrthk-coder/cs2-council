# CS2 Council

Cities: Skylines II AI council playbook. Public so any AI can read and act without this chat.

## Seats
- **Mayor** — money, zoning, milestones, taxes
- **Works** — roads, power, water, transit
- **Welfare** — health, education, crime, leisure, garbage

## Goal
Maximize population and profit. Resolve blockers that stall milestones. Log every decision.

## Files
- `playbook/standing-orders.md` — tick script, veto list
- `playbook/success-and-harm.md` — only success moves and harm moves
- `hud/icons-and-panels.md` — what the screen says
- `signatures/benefits.md` — bonus types and pick order
- `signatures/placement-and-overlap.md` — radii, spacing
- `landmarks.md` — paid trophies, early veto
- `sources/video-shelf.md` — study sources with codes
